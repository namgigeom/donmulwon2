# 돈물원 2 개발 기록

> 이 문서는 돈물원 2의 유일한 누적 개발 기록이다. 기능이나 파일을 새로 만들거나 수정할 때마다 이 문서를 갱신한다.
> 작업을 완료했다고 기록하려면 실제 파일 변경과 가능한 테스트가 확인되어야 한다.

## 프로젝트 기본 원칙

- 프로젝트명: 돈물원 2 (DONMULWON 2)
- 목표: 국내 주식시장의 낙폭과대주·테마주에서 상승 전환 신호를 발굴하고 단기 스윙 분석을 제공하는 투자 분석 시스템
- 매매 방식: 추세추종 스윙
- 기본 보유 기간: 1~2일, 최대 약 1주일
- 자동매매: 구현하지 않음
- AI 직원 및 캐릭터: 너구리 한 명만 존재
- 너구리의 역할: 시장 감시, 종목 발굴, 기술적·기업·뉴스 분석, 진입·손절·목표가 검토, 최종 보고
- 기술 방향: Python 분석 백엔드 + FastAPI + React + TypeScript 웹 프론트엔드
- 증권 데이터/계좌 연동: 토스증권 API (사용자가 제공 가능한 API 사용 정보로 연결)
- AI 모델 연결: OpenRouter API
- 기존 사무실 화면 배치와 너구리 캐릭터 자산은 보존·참고하여 웹 화면으로 이전
- 기존 코드·데이터·프롬프트·기능은 조사 없이 삭제하거나 덮어쓰지 않는다.
- Python에 이미 구현된 분석 계산은 특별한 이유가 없는 한 프론트엔드로 옮기지 않는다.
- API 키와 비밀값은 로컬 환경변수(.env)에 보관하고 Git에 커밋하지 않는다.

## 핵심 종목 발굴 조건

아래 세 조건을 모두 충족해야 정식 스캔 신호로 분류한다.

1. RSI(10)가 RSI(14)를 상향 돌파하고 두 값 모두 상승 중
2. MACD(5, 10, 9)가 시그널선을 상향 돌파하고 MACD선이 상승 중
3. 종가가 MA10을 상향 돌파

장중에만 잠시 충족한 신호와 종가 기준으로 확정된 신호를 구분한다. 세 조건 중 일부만 충족한 종목을 정식 매수 신호로 표시하지 않는다.

## 보조 검증 항목

- 거래량 및 거래대금
- 매물대, 지지·저항
- 볼린저밴드와 변동성
- 240일 이동평균선 등 장기 추세
- 기업 상황 및 관련 뉴스
- 일봉에서 발굴한 종목의 1시간봉·15분봉 진입 환경

보조 지표는 위험과 신뢰도를 판단하는 데 사용한다. 예를 들어 240일 이동평균선 아래에 있다는 이유만으로 자동 탈락시키지는 않고 장기 추세 위험으로 표시한다.

## 매매 전략 보고 항목

종목명, 시장 구분, 필수 신호 충족 여부, 신호 확정 시점, 현재 추세, 진입 구간, 손절 가격, 목표 가격, 손익비, 거래량·매물대·장기 추세 위험, 최종 의견(매수 후보/관찰/제외)을 제공한다. 데이터가 없거나 검증되지 않은 값은 추정해 사실처럼 표시하지 않는다.

## 개발 및 기록 규칙

- 작업 전 관련 파일과 기존 구현을 확인한다.
- 한 번에 작은 단위로 구현하고, 변경 범위를 명시한다.
- 새 파일 또는 수정 파일이 생기면 해당 작업을 이 문서의 작업 로그에 추가한다.
- 각 작업 로그에는 변경 파일, 구현 내용, 테스트 명령/결과, 미해결 사항, 다음 작업을 기록한다.
- 테스트하지 않은 항목은 '미검증'으로 표시한다.
- 기존 기능을 제거하거나 동작을 바꾸는 경우 이유와 영향 범위를 먼저 기록한다.
- 완료 선언은 코드와 테스트 결과를 확인한 뒤에만 한다.
