# DONMULWON 2

한국 주식시장 데이터 기반 종목 분석 GUI 프로젝트입니다. 자동매매는 수행하지 않습니다.

## 실행 환경
- Windows 10/11
- Python 3.11 이상 권장

## 설치 및 실행 (PowerShell)
```powershell
git pull origin main
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m donmulwon2.app
```

## 현재 구현
- 16:9 픽셀아트 메인 배경 및 Qt 애니메이션 푸터
- KRX 데이터 공급 계층: KOSPI/KOSDAQ breadth, 투자자별 거래대금, 종목 일봉
- RSI(10/14), MACD(5/10/9), 10/20/60/120/240일 이동평균
- 볼린저 밴드 및 거래량 20일 평균
- RSI10이 RSI14 상향 돌파 + 두 RSI 상승, MACD 상향 교차 + 상승, 종가의 10일선 상향 돌파를 모두 만족하는지 판정
- 시장 게시판용 상승/하락 종목 수, 거래대금, 투자자별 수급 데이터 조립
- 종목 분석 결과 및 시장 게시판의 SQLite 저장
- KRX 데이터 수신 실패 시 실패 사유를 반환하며 임의의 시세를 생성하지 않음

## 아직 GUI에 연결하지 않은 항목
- 실제 데이터 값을 배경 이미지의 게시판/차트/숫자 위치에 렌더링
- 백그라운드 작업 스레드 및 진행률 UI
- 종목 발굴 결과 목록, 상세 분석 리포트, 캔들/지표 차트 위젯
- 테마/뉴스 수집 및 AI 시장 한줄 요약
- 진입/목표/손절 가격 산출과 백테스트 검증

## 데이터 주의
KRX 데이터는 거래일 기준 일봉 데이터이며, 실시간 호가/체결 데이터가 아닙니다. KRX 응답 또는 네트워크 상태에 따라 수집이 실패할 수 있습니다. 투자자별 수급은 원천 데이터의 컬럼 구성을 그대로 보존합니다. 데이터가 없는 항목은 추정값으로 채우지 않습니다.
